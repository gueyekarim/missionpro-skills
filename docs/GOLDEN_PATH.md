# MissionPro Skills — Golden Path

## MP-001 — Public Project Risk Capability

Ce scénario constitue le test de référence du MVP. Toute évolution importante doit préserver son fonctionnement de bout en bout.

### Persona
Amadou, chef de projet public.

### Need
**Je veux être capable d’identifier et prioriser les risques d’un projet public.**

### Expected journey
1. Amadou saisit son objectif dans Capability Home.
2. NOVA construit une Capability structurée.
3. Amadou accepte ou modifie la fiche.
4. NOVA lance le diagnostic.
5. Le système établit un niveau observé, par exemple 2/5.
6. Amadou vise un niveau cible, par exemple 4/5.
7. NOVA génère un Personal Capability Path adapté au gap.
8. Amadou suit une Learning Unit pertinente.
9. NOVA lui propose un Challenge professionnel.
10. Amadou produit une matrice de risques.
11. NOVA Assessor évalue la production avec une rubric explicite.
12. Le système fournit score, forces, faiblesses, preuves manquantes et prochaine action.
13. Amadou choisit d’enregistrer la production comme Evidence.
14. Le système recalcule ou recommande le niveau de maîtrise.
15. Le Capability Passport est mis à jour.
16. NOVA recommande la prochaine action vers le niveau cible.

## Pass condition
Le MVP n’est considéré comme fonctionnel que lorsque les seize étapes peuvent être exécutées sans rupture de données ni reconstruction manuelle du contexte.

## Core acceptance chain
**Intent → Capability → Diagnostic → Path → Learning → Practice → Assessment → Evidence → Mastery → Passport.**
