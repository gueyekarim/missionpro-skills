# Prompt 06 — Sprint 4: Practice & Assessment

Proceed only after NOVA Tutor acceptance.

## Objective
Move from learning to observable performance.

Build a Practice Lab supporting at minimum:
- Exercise
- Case
- Challenge
- Real-work-style task

A practice activity must be linked to a Capability and mastery criteria.

Build NOVA Assessor using explicit rubrics. Assessment output must include:
- overall score;
- criterion-level scores;
- strengths;
- weaknesses;
- missing evidence;
- reasoning/explanation;
- recommended next action;
- proposed mastery implication, if justified.

For MP-001, use a rubric covering at least:
- risk identification;
- probability/impact assessment;
- prioritization;
- treatment strategy;
- quality of reasoning and deliverable.

Assessment provenance must distinguish AI assessed from human validated and higher verification levels.

The learner must be able to review the criteria and result. Preserve a route for reassessment/contest rather than treating model output as infallible.

Do not yet implement full Capability Passport or organization analytics.

Run tests including structured-output validation and failure handling.
STOP after Sprint 4.
