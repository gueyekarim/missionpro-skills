# Prompt 03 — Sprint 2: Diagnostic Engine

Proceed only after Sprint 1 acceptance.

## Objective
Determine demonstrated current capability before prescribing learning.

Implement a diagnostic session linked to a Capability and User.

The diagnostic may combine:
- structured self-assessment;
- knowledge questions;
- mini-cases;
- short production/performance tasks.

NOVA diagnostician must use explicit capability criteria and return validated structured results.

## Required output
- Observed Level
- Target Level
- Capability Gap
- strengths
- weaknesses
- missing evidence
- explanation of the result
- recommended development priorities

Use the invariant:
`Capability Gap = Required/Target Capability - Observed Capability`.

Self-assessment alone must never establish verified mastery.

Persist diagnostic results and provenance. Make the result explainable and reviewable.

## MP-001
Diagnose the user against `CAP-PROJ-RISK-001`, including ability to identify risks, assess probability/impact, prioritize and propose treatment.

## Do not build
Full adaptive curriculum, evidence portfolio, passport or organization mode.

Run tests and provide acceptance evidence.
STOP after Sprint 2.
