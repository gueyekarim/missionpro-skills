# Prompt 10 — QA, Security & MVP Readiness

Run only after MP-001 Golden Path passes.

Do not add new product scope. Harden what exists.

## Review
Audit:
- authentication and authorization;
- user-data isolation;
- server/client boundaries;
- secret handling;
- AI prompt/input/output validation;
- database constraints and migrations;
- error handling;
- logging and accidental sensitive-data exposure;
- dependency/security issues;
- accessibility basics;
- responsive usability;
- performance of core MVP routes;
- test coverage of critical domain invariants;
- setup/deployment documentation.

## Product invariants to verify
- Capability remains central.
- Learning completion is not mastery.
- Mastery is traceable to evidence/assessment.
- AI assessment is not certification.
- NOVA remains contextual and server-side.
- MP-001 works end-to-end.
- Deferred features have not displaced the core MVP.

## Release report
Return:
1. architecture summary;
2. security findings and fixes;
3. test suite and results;
4. migration/seed status;
5. MP-001 E2E status;
6. known limitations;
7. technical debt;
8. MVP release blockers;
9. PASS / CONDITIONAL PASS / FAIL recommendation for MVP pilot.

Do not start Organization Mode, marketplace, payments, community, marketing automation or other post-MVP features.
STOP after the readiness report.
