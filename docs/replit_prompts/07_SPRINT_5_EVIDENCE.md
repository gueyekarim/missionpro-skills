# Prompt 07 — Sprint 5A: Evidence Engine

Proceed only after Practice & Assessment acceptance.

## Objective
Make demonstrated work the basis of mastery.

Build the Evidence Portfolio and evidence capture flow.

After an assessed practice or appropriate real-work task, allow:
**Save this work as evidence?**

Evidence must preserve traceability to:
- user;
- capability;
- task/activity where applicable;
- assessment;
- artifact/content reference;
- criteria;
- score/result;
- provenance/assessor type;
- verification status;
- timestamp.

Support the governance ladder:
Self-declared → AI assessed → Human validated → MissionPro verified → Externally certified.

Do not automatically promote AI-assessed evidence to certified status.

Create an Evidence Portfolio view grouped by capability, with clear status and assessment trace.

Mastery calculation/update logic must be evidence-aware and explainable. A completed lesson alone is not evidence of capability.

## MP-001
A completed and assessed risk-prioritization challenge can be stored as evidence for `CAP-PROJ-RISK-001` and retrieved from the portfolio.

Run persistence, authorization and provenance tests.
STOP before Capability Passport.
