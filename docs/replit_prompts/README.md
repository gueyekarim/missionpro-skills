# MissionPro Skills — Replit Prompt Chain

This folder contains the controlled implementation prompts for MissionPro Skills.

## Rule
Run one prompt at a time. Do not proceed to the next prompt until the previous stage has been reviewed and accepted.

## Sequence
1. `00_AUDIT.md` — inspect repository and establish baseline.
2. `01_SPRINT_0_FOUNDATION.md` — implement technical foundation.
3. `02_SPRINT_1_CAPABILITY_BUILDER.md` — capability registry and builder.
4. `03_SPRINT_2_DIAGNOSTIC.md` — diagnostic engine and capability gap.
5. `04_SPRINT_3_LEARNING_PATH.md` — personal capability path.
6. `05_SPRINT_3_NOVA_TUTOR.md` — contextual NOVA Tutor.
7. `06_SPRINT_4_PRACTICE_ASSESSMENT.md` — practice, challenge and assessment.
8. `07_SPRINT_5_EVIDENCE.md` — evidence engine and portfolio.
9. `08_SPRINT_5_CAPABILITY_PASSPORT.md` — capability passport and mastery update.
10. `09_GOLDEN_PATH_E2E.md` — validate MP-001 end-to-end.
11. `10_QA_SECURITY_RELEASE.md` — QA, security and MVP readiness.

## Product invariant
MissionPro Skills is capability-first, not course-first.

Core lifecycle:

**Capability → Diagnosis → Development → Practice → Evidence → Assessment → Mastery → Performance**

NOVA remains a server-side orchestrator for the MVP.

## Source of truth
Every prompt must be executed in accordance with the repository documentation, especially the Blueprint, PRD, Data Model, NOVA Architecture, Product Principles, UX Flows, Golden Path and MVP Roadmap.
