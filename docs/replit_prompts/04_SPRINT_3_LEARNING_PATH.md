# Prompt 04 — Sprint 3A: Personal Capability Path

Proceed only after Diagnostic acceptance.

## Objective
Transform a measured capability gap into a personalized development path.

Build `Your Path to Mastery` using stages such as:
1. Understand
2. Learn
3. Practice
4. Simulate / Challenge where appropriate
5. Apply
6. Prove
7. Master

Every learning unit must be attached to a Capability and must address an identified gap or mastery criterion.

NOVA Architect/Mentor should generate or select the path from:
- capability definition;
- observed level;
- target level;
- diagnostic weaknesses;
- existing evidence;
- role/context.

Use the pedagogical relationship:
**Capability → Learning Outcomes → Activities → Evidence → Assessment**.

Allow progress tracking but do not confuse completion with mastery.

## MP-001
Generate a path from the user's diagnosed level toward the target level for public-project risk identification and prioritization.

Run tests and show that path generation is deterministic enough to validate structurally even when content is AI-assisted.

STOP after this stage. Do not automatically build NOVA Tutor.
